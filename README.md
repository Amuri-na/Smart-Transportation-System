# Smart Transportation System

An AI-powered transportation information platform designed to reduce uncertainty in Ethiopian public transportation by providing taxi availability, queue information, and estimated waiting times.

## Project Goal

Help passengers know:
- Available taxis at stations
- Queue length
- Estimated waiting time
- Better transportation options

## Solution Components

### 1. Tera Askebari Photo Reporting + AI Analysis
Collect station images and use computer vision to estimate taxi numbers and queue length.

### 2. Queue Sharing / Lada Matching
Match passengers with similar destinations to reduce waiting time and cost.

### 3. Driver GPS-Based Availability Detection
Use driver location information to estimate taxi availability.

### 4. Google Maps Integration
Use map and location data to improve transportation information.

### 5. Passenger Crowd Reporting
Allow passengers to provide real-time station updates.
