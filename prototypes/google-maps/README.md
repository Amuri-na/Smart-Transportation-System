# Google Maps Integration Prototype

## Goal

Test how Google Maps and location services can help provide transportation information to passengers.

## Features to Test

- Display taxi stations on a map
- Show user current location
- Calculate distance to stations
- Show route information
- Estimate travel time
- Explore traffic data availability

## Current Status

Planning phase.

## Technologies to Test

- Google Maps API
- Flutter/other frontend options (to be decided)
- Location services
