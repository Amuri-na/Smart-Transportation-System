# Google Maps API Experiment

## Objective

Test Google Maps functionality required for the transportation platform.

## Experiments

### Experiment 1: Map Display
Question:
Can we display an interactive map?

Success:
A map loads successfully.

---

### Experiment 2: Location
Question:
Can we get the user's current location?

Success:
User location appears on the map.

---

### Experiment 3: Station Markers
Question:
Can we display taxi stations?

Success:
Taxi stations appear as markers.

---

### Experiment 4: Distance Calculation
Question:
Can we calculate distance between user and station?

Success:
Distance is displayed.

---

### Experiment 5: Route Information
Question:
Can we show route and estimated travel time?

Success:
A route can be generated.
