# Google Maps Integration Prototype

## Objective

Test whether Google Maps services can provide useful location and transportation information for taxi users.

## Prototype Features

### 1. Taxi Station Map Display

The system should:
- Display taxi station locations
- Show station markers on the map

### 2. User Location

The system should:
- Detect user's current location
- Show user position on the map

### 3. Distance Calculation

The system should:
- Calculate distance between user and station
- Display estimated distance

### 4. Route Information

The system should:
- Generate route to station
- Show estimated travel time

### 5. Traffic Information

The system should:
- Explore available traffic information
- Evaluate if it improves waiting-time estimation

## Technology

Frontend:
- Flutter
- Google Maps Flutter Plugin

APIs:
- Google Maps SDK
- Directions API
- Geocoding API

## Success Criteria

The prototype is successful if:
- A user can open a map
- Taxi stations appear
- User location appears
- Route information can be displayed
